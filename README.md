# mowtest
MyOnlineWorksheet testing playground

Math practice for kids: printable worksheets (legal paper, two-sided) and an audio practice page.

| Page | What it is |
|---|---|
| `index.html` | The list of worksheets, plus the "Name on the worksheets" box (saved only on each device) |
| `audio-practice.html` | One problem at a time: hear it, say or tap the answer; mini-lessons for misses; slow or missed problems come back until they're fast |
| `multiplication-worksheet.html` | Multiplication · 2, 3, 5, 10 |
| `multiplication-3-and-5.html` | Multiplication · 3 & 5 |
| `division-2-3-5-10.html` | Division by 2, 3, 5, 10 |
| `mixed-multiply-divide-2-3-5-10.html` | × and ÷ mixed |
| `themes.js` | Themes (Classic, Cats) used by every page; picked on the list page and saved only on each device |

Every page makes new problems each time it's opened. Settings (tables, rows, paper size, goal seconds, etc.) are at the top of each page's script.

## Publishing with GitHub Pages
Settings → Pages → Build and deployment → Source: **Deploy from a branch**, Branch: **main**, folder **/ (root)** → Save.
The site appears at `https://abmuqtadir1.github.io/mowtest/` after a minute or two.
(GitHub Pages needs a public repo on the free plan, or GitHub Pro for a private repo. The site itself is public either way.)
